# v2.0.0 release notes

Version 2.0.0 supports the revised manuscript **“Quadrupole-limited control windows for an atomically addressable 49Ti nuclear-spin qudit.”**

## New in v2.0.0

- reconstructed and validated 1944-scenario 16-level sensitivity grid;
- low-field minimax search identifying 1.0292 T and the 0.992-1.069 T robust interval;
- dense static dual-manifold control sweeps used to locate the first 99% fidelity crossings;
- revised control interpretation with coherent-revival handling;
- one-at-a-time sensitivity decomposition;
- field-quadrupole design map and general maximum-field rule;
- revised manuscript, Supplementary Information and publication figures.

The earlier IBM encoding benchmark is not part of the revised scientific narrative. The static-manifold control calculations remain model results and do not include stochastic electron switching.
