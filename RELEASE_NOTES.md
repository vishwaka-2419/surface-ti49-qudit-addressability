Initial reproducibility release accompanying the submission “Quadrupole-limited spectral addressability of an atomically addressable 49Ti nuclear-spin qudit.”

This release contains manuscript-level scripts, exact frozen derived tables, final IBM echo summaries, environment metadata, SHA-256 manifests, and publication figures. It contains no API credentials.
